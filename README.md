# 🎮 Python Inventory System

A simple **Python inventory management system** designed around a game character's inventory.

The program stores items in a dictionary using the structure:

python
item: (category, quantity)


It allows the user to view, add, use, search, remove items, and calculate the total number of items.

## ✨ Features

* 🎒 Display inventory
* ➕ Add an item
* 🧪 Use an item and update its quantity
* 🔍 Search for an item
* 🗑️ Remove an item
* 📊 Calculate the total number of items

## 🔄 Program Flow
_Start_
* Create Inventory Dictionary
* Store Items as: item: (category, quantity)
* Display Inventory
* Add an Item
* Use an Item → Update Quantity
* Search for an Item
* Remove an Item
* Calculate Total Number of Items
_End_
